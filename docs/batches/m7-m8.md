# Batches m7 and m8: whole-file matching of main.rel, functions ≤ 512 B (2026-09-08)

Every never-attempted function of main.rel under 512 bytes, selected by
translation unit so each agent sees the TU's typed header, on Luna via Codex.
m7 ran 16-wide and was stopped at 791 of 1,627; m8 finished the rest 64-wide.

| | m7 (16-wide, interrupted) | m8 (64-wide) |
|---|---|---|
| functions | 791 | 835 |
| matched | 406 (51%) | 459 (55%) |
| link-rejected | 0 | 0 |
| cost | $8.99 | $8.71 |
| wall | 1 h 27 min | 22 min |
| throughput | 9 functions/min | 38 functions/min |

Per-function spend was identical ($0.011); the 64-wide run was four times
faster with no change in match rate or link failures, so 64 is the width to
use. Six of m8's matches went through the literal-pool retargeting.

## Notes

- m7 was interrupted by hand (the width was the bottleneck, not the model);
  its 13 in-flight claims were closed as aborted and its 55 pending matches
  link-verified separately.
- A header experiment between the two runs (declaring small globals wider
  than their accessed field as arrays) broke 14 matched units that read those
  globals as scalars and was reverted before m8 started.
